## 2024-10-14 - Replace native title attributes with custom Tooltip component
**Learning:** Native `title` attributes on interactive elements (like `button`) provide a poor user experience, especially on touch devices, and lack visual consistency and stylability across browsers. Native `title` tooltips also delay their appearance and do not follow design system guidelines for accessibility. Using standard `Tooltip` components from Shadcn UI / Radix UI not only ensures visual cohesion but provides a robust way to associate a description with interactive components using `TooltipContent`.
**Action:** When creating or fixing icon-only or interactive buttons that need descriptive labels, avoid using the `title` attribute. Always wrap the button inside a `<Tooltip>` with a `<TooltipTrigger asChild>` and place the description inside `<TooltipContent>`. Remember to preserve all existing ARIA attributes and interaction handlers when migrating.
